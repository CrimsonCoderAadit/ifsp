# Known failures and evidence limits

- **No measured real-set accuracy yet.** Commons downloads contain many non-MTC images and unreadable boards. Six image labels are suggestions awaiting human confirmation; the 70/30 dev/test evaluation deliberately refuses to run without confirmed labels.
- **Unknown numeric routes.** In a real Commons photo, the visible LED route `576` is not in the current GTFS catalogue. An early matcher mapped it to `57G`; the integrated reader now withholds a route rather than announcing that wrong bus. This may suppress a legitimate route until the feed is updated.
- **OCR model comparison pending.** The default runtime uses PP-OCRv4 mobile ONNX models. PP-OCRv5 mobile and server models were downloaded and tried on three unconfirmed Commons photos. Both missed the visible 21G board that v4 read; the server variant also falsely matched route 6 on a visible 56 board in this exploratory run. V4 remains the demo default. A confirmed dev set is required for a fair accuracy and latency comparison. No before/after accuracy gain is claimed.
- **Real video and voice capture pending.** The bundled synthetic clip had zero bus tracks; its 150-frame run verifies the loop but not bus-reading accuracy or risk interruption. The team must add real MTC footage in `data/real/own/`.
- **Detection and crop limits.** Distant buses, side views, occluded boards, windshield glare, LED refresh artifacts, Tamil text, registrations, and depot IDs can cause no-read or false reads. The confidence threshold and two-of-three video vote reduce but do not eliminate wrong routes.
- **Bus speech priority.** HIGH/CRITICAL warnings use the existing preemptive scheduler. The web page shows warnings received over the integrated WebSocket; physical interruption timing remains unmeasured on this machine.

Collection snapshot: 82 Commons images downloaded, 0 Roboflow images (API key absent), 0 team images, 6 unconfirmed suggestions, 0 confirmed route labels. The wider Tamil Nadu category download is incomplete because of intermittent TLS resets. No per-source or per-board accuracy is available.
